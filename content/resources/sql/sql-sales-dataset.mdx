# SQL E-Commerce Sales Practice Database

If you are preparing for data analyst interviews or upgrading your SQL querying speed, practicing on small, static datasets will not prepare you for production environments. This database is normalized, indexed, and pre-populated with transactional records to test your optimization queries.

<Info title="Database Scripts">
  This free download contains both PostgreSQL and MySQL compatible schema creation scripts, including indexing configurations to test performance gaps.
</Info>

### Relational Schema Diagram

The database consists of 4 main relational tables:
- **`users`**: Contains demographic details, signup events, and user tiers.
- **`orders`**: Transaction records with status, checkout totals, and timestamps.
- **`items`**: Item catalogs, price ledgers, and category references.
- **`order_items`**: Relational bridge containing item quantities and line totals.
