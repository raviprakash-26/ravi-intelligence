# Midjourney Cinematic Portrait Studio

Generate premium, high-resolution portrait imagery for landing pages, team rosters, and profile cards using detailed studio descriptors.

<Tip title="Studio Lighting Hack">
  Add **`warm backlighting`** to your lighting styles to create a professional glow effect around subject hair contours.
</Tip>

### Midjourney Engine Settings
This setup targets Midjourney version **6.0** with aspect ratio `16:9` and high-fidelity rendering outputs.
